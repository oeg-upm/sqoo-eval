# Evaluation Results

This website presents the evaluation results obtained using
**SQOO (Software Quality Observatory Orchestrator)**.

SQOO automates research software cataloguing and quality
assessment by integrating different analysis tools.

## Evaluation Cases

The system was evaluated using three different types
of GitHub stakeholders.

### Researcher — SergioZSZ

Evaluation of repositories belonging to an individual researcher.

[Explore Catalog](researcher-eval/)

### Research project — FAIR2Adapt

Evaluation of repositories associated with the FAIR2Adapt
research project.

[Explore Catalog](research-project-eval/)

### Research group — OEG-UPM

Evaluation of repositories maintained by the
Ontology Engineering Group at UPM.

[Explore Catalog](research-group-eval/)

## About SQOO

SQOO integrates tools for metadata extraction, software
cataloguing, FAIR assessment and software quality evaluation.
